# 🚀 Proyecto Onboarding Junior - Fullstack Roadmap

Este es mi entorno profesional de desarrollo donde estaré aplicando metodologías ágiles y buenas prácticas de ingeniería de software.

## 🛠️ Stack Tecnológico
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Control de Versiones:** Git & GitHub
- **Despliegue Continuo (CI/CD):** Vercel / Netlify
- **Metodología:** Kanban (GitHub Projects)

## 📁 Estructura del Proyecto
- `/src`: Código fuente de la aplicación.
- `/docs`: Documentación técnica y registros de aprendizaje.
- `/assets`: Imágenes y recursos multimedia.

## 📝 Registro de Decisiones (ADR)
Todas las decisiones técnicas se encuentran documentadas en la carpeta `docs/decisions.md`.
